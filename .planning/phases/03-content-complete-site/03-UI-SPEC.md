## Spacing Scale

Declared values (all multiples of 4). Tailwind's default 4 px step is kept; named stops below are the only ones layout code may use for gaps, padding and margins.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip inner gap, underline offsets |
| sm | 8px | Inline gaps (logo to company, icon to label), chip padding-block |
| md | 16px | Default gap, phone page margin, grid gutter minimum, card padding on phones |
| lg | 24px | Gap between stacked blocks inside a section, dialog padding on phones, nav link gap |
| xl | 32px | Gutter maximum, dialog padding on desktop, row padding-block |
| 2xl | 48px | Gap between a section heading and its content |
| 3xl | 64px | Nav height (`--nav-h`), top bar height, large gaps between blocks |
| 4xl | 96px | Section spacing, "tight" mood (Experience, Projects band, Skills, Education) |
| 5xl | 160px | Section spacing, "airy" mood (before About) |

Section spacing moods (DESIGN.md section 5, assigned on purpose): Experience, Projects, Skills, Education use **tight** (4xl top and bottom). About uses **airy** (5xl top). Hero uses its own height rule. Contact/footer finale is **full viewport** (`min-height: 100svh`).

Grid gutter and outer margin are fluid per DESIGN.md: `clamp(1rem, 2vw, 2rem)` (16 to 32 px). Outer margin equals the gutter.

Exceptions (each justified):

| Exception | Value | Reason |
|-----------|-------|--------|
| Touch targets | 44 px min-height and min-width on every interactive control (buttons, nav segments, summary rows, toggle, dialog controls); links in running text excepted | WCAG 2.2 target size and the awwwards 44 px primary rule. 44 = 11 x 4, so still on the 4 px grid |
| Hairlines and rings | 1 px borders, 2 px focus ring and indicator, 2 px ring offset | Stroke widths, not spacing |
| Radii | 4 px and 9999 px only (D-06) | Shape rule. One declared exception: the expanded pill panel keeps 28 px (half the 56 px pill height) so the pill-to-panel morph reads as one shape (IX-07) |
| Pill nav | collapsed height 56 px, bottom offset 16 px + `env(safe-area-inset-bottom)` | Thumb zone. 56 = 14 x 4 |
| Logo slot | 24 px square slot, logo drawn at 20 px | Aligns logo and monogram chips (D-07) |

## Typography

One family, Archivo Variable. Ladder is the DESIGN.md section 5 ladder (D-03), reproduced here with resolved pixel values so it is checkable. `vw` terms resolve at the named viewport; desktop sizes clamp as DESIGN.md states.

| Role | Token | Size (390 / 1280 px viewport) | Weight | Line height | Tracking | Axis and use |
|------|-------|-------------------------------|--------|-------------|----------|--------------|
| Display | `--t-mega` | 100 px phone override / 170 px (min 60, max 192) | 800 | 0.86 | -0.045em | wdth 100. Hero h1 only. **Refinement:** below 768 px use `clamp(3.75rem, 0.9rem + 22vw, 6.75rem)` so "Aaron" and "Phan" fill about 80 percent of the 358 px content width (DESIGN.md wireframe says "fills width"; the desktop coefficient gives only about 54 percent on a phone). 6.75rem = 108 px equals the desktop value at 768 px, so there is no jump at the breakpoint. Widths are estimates from average Archivo glyph widths; the executor measures and the QA loop confirms |
| Wordmark | `--t-wordmark` | fit to container (`container-type: inline-size`, `cqi`) | 800 | 0.8 | -0.03em | wdth 100 day, wdth 125 night (`font-stretch`). Footer finale and 404. Nav wordmark uses the `--t-m` size at weight 800 with the same width rule |
| Heading | `--t-xl` | 41 px / 84 px (min 40, max 88) | 750 | 0.95 | -0.03em | Section h2, education date lead |
| Statement | `--t-l` | 25 px / 37 px (min 24, max 40) | 500 | 1.15 | -0.015em | Role line, skills sentences, bio lead, sleeve titles, contact email |
| Title | `--t-m` | 19 px / 23 px (min 19.2, max 23.2) | 600 | 1.35 | -0.005em | Experience company and row titles, dialog subheads, pill panel links, nav wordmark |
| Body | `--t-body` | 16 px / 17 px | 400 | 1.55 | 0 | Bullets, bio, dialog copy. Measure at most 62ch |
| Label | `--t-s` | 14 px | 500 | 1.45 | 0.005em | Nav links, dates, captions, corner facts, button labels |
| Micro | `--t-xs` | 13 px | 500 | 1.4 | 0.01em | Stack chips and sleeve metadata only |

Rules:

- **Declared sizes:** eight tokens (DESIGN.md ladder, locked by D-03). The generic "3 to 4 sizes" heuristic is for app UIs; this is a poster ladder where five of the eight are fluid. **Declared weights:** 400, 500, 600, 750, 800 (also locked by DESIGN.md). Both counts are flagged to the checker as owner-locked deviations, not oversights. Do not add a size or weight beyond this table.
- Old Tailwind modular sizes (`text-xs` through `text-5xl`) are deleted from `@theme`; `--text-mega/xl/l/m/body/s/xs` replace them with `--line-height`, `--letter-spacing` and `--font-weight` modifiers. After the swap, grep the repo for the old names (`src/layout/Section.tsx` currently uses `text-3xl font-semibold`).
- Display type: `margin-inline-start: -0.055em` on the h1 (optical alignment to the body left edge); `text-wrap: balance` on h1/h2; `white-space: nowrap` plus size from `cqi`/`vw` for the wordmarks.
- Numerals: `font-variant-numeric: tabular-nums` on dates, GPA, graduation date, project index, dialog index.
- Real typographic characters: apostrophes as U+2019, date ranges with U+2013 and non-breaking spaces (`June 2026&nbsp;&ndash;&nbsp;August 2026` rendered as `June 2026 – August 2026`, `white-space: nowrap`). **No em dashes in visible copy.**
- Sentence case everywhere. No uppercase eyebrow labels above headings. Wordmarks "PHAN" and "PHVNTM" are the only all-caps text and are typed in caps, not `text-transform`.
- Descenders: with line-height 0.86 on the h1 and 0.8 on wordmarks, verify no clipped g, j, p, q, y (add `padding-bottom: 0.08em` on any clipped line wrapper).
- Selection color: `::selection { background: var(--primary); color: var(--on-primary) }` (audited pair, ratio 6.07 light / 5.66 dark).
- **CLS guard (WPO):** `@font-face` fallback "Archivo Fallback" built from a local system face with `size-adjust`, `ascent-override`, `descent-override` tuned so swapping to Archivo shifts the hero by less than 2 px at 390 and 1280. Gate: throttled-phone `mobileCls` under 0.05. Preload of the latin `wdth` woff2 is allowed (Vite does not rewrite a bare preload; use `?url` import or a small `transformIndexHtml` step) and is the executor's call if LCP is near the limit.

## Global Chrome

### Skip link
First focusable element in the React tree. Text "Skip to main content". Hidden until `:focus`, then fixed at top 16 px / left 16 px, pill, ground `--text`, label `--background`, `--t-s` weight 500, min-height 44 px, padding-inline 24 px, z `--z-skip-link`, plus the standard ring. Enter moves focus to `main#main` (focusable via `tabindex="-1"`). Observable: `k-01` keyboard frame shows it.

### Wordmark
`PHAN` in light, `PHVNTM` in dark, both strings present in `aria-hidden` spans, swapped by CSS on `[data-theme]` (no JS state, no flash). The home link `href="#hero"` carries `aria-label="Aaron Phan, home"` in both themes. Night widens the wordmark only (`font-stretch` 125%). Hover and focus: 2 px underline (currentColor) draws left to right in 220 ms, `ease-out`; reduced motion shows it instantly. (Chosen over the nav roll so Phase 4's A to V flip can own the first glyph without a second animator.) The animated flip is Phase 4 (IX-18); wrap the A/V glyph in its own span now so Phase 4 can target it.

### Desktop nav (768 and up, D-18)
- 64 px tall, `position: sticky; top: 0`, ground `--background`, 1 px bottom border `--border`, always visible (no hide on scroll), z 40.
- Left: wordmark. Center-right: six links in this order and with these labels: Experience, Projects, About, Skills, Education, Contact (`--t-s`, weight 500, 24 px gap, 44 px min-height). Right: theme toggle, then a **Resume** button (nav-size CTA: pill, 44 px high, padding-inline 24 px, outlined `--border-strong` at rest, `--t-s`; same ink-flood treatment as other CTAs; `download` attribute).
- Active link: `aria-current="location"` and a 2 px `--accent` bar 4 px under the label that slides between links (IX-08, motion `layoutId`, spring `snappy`; reduced motion: bar jumps). With JS animation chunk not loaded, the bar still appears under the active link without sliding.
- Link hover and keyboard focus: label roll (below). Exactly one `navigation` landmark exposed at a time (`display: none` on the inactive form), labelled "Primary".

### Phone top bar (below 768, D-19)
Not fixed, 64 px tall, above the hero. Left: wordmark. Right: theme toggle (44 px target). Visible on first paint so the day and night switch is the first thing a phone visitor can touch.

### Pill nav (below 768, IX-07, reference 445)
- Fixed, horizontally centered, bottom 16 px + safe area, z 50. Collapsed: height 56 px, pill (9999 px), ground `color-mix(--surface 92%, transparent)` with blur, 1 px `--border-strong` border, `--shadow-lg`. Placed at the end of the DOM (after the footer) so keyboard order finishes there.
- Three segments, each at least 44 px tall and 96 px wide, `--t-s` weight 500: **Experience** and **Projects** (anchors to `#experience`, `#projects`) and **Menu** (native `<button aria-expanded aria-controls>`). The segment of the section in view is filled `--accent` with `--on-accent` label and `aria-current="location"`; otherwise transparent. `:active`: `--secondary` fill.
- Expanded panel (Menu tapped): the same element morphs in place (motion `layout`, spring `gentle`, `layoutRoot` on the fixed element) to width `min(100vw - 32px, 360px)`, radius 28 px, max-height `80dvh` with internal scroll. ## Toast (IX-09, NAV-03)
- Persistent visually hidden `role="status"` (`aria-live="polite"`) region present at mount; the message text is written into it on activation. The visual toast is `aria-hidden` so it is not announced twice.
